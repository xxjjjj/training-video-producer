# 培训视频制作 · training-video-producer

可分发版 **0.5.5**。把培训资料、SOP、完整旁白、截图或已有动画HTML，整理成有实际动作、完整配音和字幕的培训视频。

适合教学和操作培训。AI负责理解资料、设计和编写动画；本包提供制作流程、媒体准备、配音与渲染工具。它不是安装后无需配置的一键视频应用，也不附带AI模型或语音额度。

## 能做什么

- 资料核对、教学分镜、代表性样片、分章节MP4和可编辑HTML工程。
- 用HyperFrames/GSAP表现字段移动、操作步骤和结果变化，保留完整字幕。
- 配音可选免费 Edge TTS（晓晓、云希等），或 MiniMax 标准音色/已有授权克隆音色。
- 接续已有工程，只重做受修改影响的音频、字幕或章节。

本版不创建克隆音色，不包含任何人的音色ID或声音样本。需要新建克隆音色时，应另用合适的授权工具配置后接入。模板不能保证每次自动生成的内容都正确，正式交付前仍需审阅。

## 安装

下载发行ZIP，解压后顶层应为 `training-video-producer/`，目录内包含 `SKILL.md`。

- WorkBuddy：通过其技能导入入口导入ZIP；已有同名技能先备份并核对自定义修改。
- Codex或兼容宿主：把该文件夹放到宿主支持的用户技能目录。沿用已有技能位置，避免同时安装多个同名版本。
- 使用已有对话时，要求代理重新读取新安装的 `SKILL.md`。

需要本地文件读写与命令执行能力，以及Node.js 22+（含npm）。依赖固定为HyperFrames 0.8.42、GSAP 3.14.2等，详见package-lock.json。可先对代理说：

> 配置training-video-producer技能，检查缺少的环境；这次只配置，不调用配音、不制作视频。

手动检查时在技能文件夹运行：

```sh
node scripts/studio.mjs doctor
node scripts/studio.mjs setup
```

setup只在需要安装依赖时运行，会联网下载程序和浏览器。首次配置的详细说明、权限和替代路径见 [安装指南](references/install.md)。识别字幕可能另外需要whisper.cpp及多语言模型；优先复用本机已安装工具。

## 第一次制作

附上资料，并说明受众、学习目标、约略时长、分享人和声音要求。例如：

> 使用training-video-producer，把附件SOP做成培训视频。观众是第一次操作的新同事，学完能独立完成申请。时长约3分钟，不凑时长。保留完整字幕，画面展示实际操作和状态变化。先核对资料并列出缺失信息，做30–60秒有代表性的样片；确认后再扩展全片。使用我已选定的声音。已有成果继续复用。

先确定旁白和声音，完成对应配音及字幕时间，再编排正式动画。反馈时标明时间点和希望发生的变化。不同课程使用独立项目，保留分镜、音频、字幕与版本记录。

## 声音、联网和费用

- 新项目默认免费 Edge TTS 晓晓，不用额外指定或反复选择。已有项目保持已确认的服务与音色；选择 MiniMax 标准音色或克隆音色时才走付费。CLI 默认也为 Edge；旧 MiniMax 命令须显式补上 `--provider minimax`。
- 想用免费配音，告诉代理：“使用免费 Edge TTS 配音，选择晓晓；保留完整字幕，不切换付费服务。”已有克隆音色继续用 MiniMax。两种方案的安装与命令见 [配音配置](references/tts.md)。
- Edge TTS 需 Python 和网络，无需 API Key；旁白发往微软在线语音服务。通过第三方 edge-tts 客户端调用，不承诺无限量、永久免费或可用性；失败不自动切到收费服务。不支持声音克隆。
- MiniMax配音使用安装者自己的API账号和额度。通过 `MINIMAX_API_KEY`、个人私密文件的 `--key-file`，或macOS可选钥匙串方式提供凭证；不要写进技能或公共项目。账号会员不等于语音API额度。
- `tts.mjs plan` 只做本地预检；`generate --provider minimax` 会把旁白文本、音色和模型参数发送给所选地区的MiniMax API，并使用凭证认证。中国站为 `api.minimaxi.com`，国际站为 `api.minimax.io`。`voices` 会请求所选服务的音色信息。
- MiniMax 在线配音按供应商现行价格收费；本包不收取配音费，也不承诺价格或额度。已有音频可直接接入，无需调用MiniMax。
- setup访问npm及依赖所需的官方分发源，浏览器、识别程序或模型首次安装也可能需要下载。不要把依赖下载等同于离线运行。
- 本包本地渲染流程没有自动发布课程或上传媒体的步骤；通过本包调用HyperFrames时关闭其自动技能安装、自动升级和遥测。AI宿主本身可能将提供给它的资料发送到其模型服务，按所用宿主的数据政策处理，不能据此承诺资料始终不出电脑。

本包会执行Node命令、启动本地浏览器/媒体工具并在用户选定项目路径创建产物。由用户和宿主决定允许的权限；不要为安装关闭安全校验。

## 验证范围

0.5.5通过21项脚本测试，覆盖原有流程、免费/付费隔离、原稿保留、失败停止、断点复用与符号链接安装。本次未调用付费配音或导出完整课程。已有macOS制作经验；Windows/Linux真实整条制作流程尚未验收。新机器应先跑小样，不把测试通过等同于课程内容、声音或动画已获确认。
