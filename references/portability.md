# 环境适配

## 先检查能做什么

检查文件读写、Node.js 或适用脚本运行时、浏览器、所需库、FFmpeg/ffprobe、中文字体以及当前权限。优先 PATH 或用户显式配置，记录检查结果。不要因为有浏览器就假设能录制其声音。

制作文稿和分镜不依赖配音服务；HTML 预览不一定具备 MP4 编码能力。缺少工具时继续不受影响的产物，明确哪个阶段尚不能运行。

## 通用边界

- 运行时传入项目目录与输出目录；脚本不依赖开发者电脑的绝对路径。
- 不依赖 Codex 专属 MCP 名称、线程协调 API、内置 Node 缓存路径或 WorkBuddy 专属连接器名称。
- Playwright 等库作为项目依赖解析，或使用宿主实际提供的等价能力；浏览器路径可发现/配置，不固定为 macOS 应用目录。
- FFmpeg/ffprobe 由环境配置，不能把临时下载目录当长期安装位置。
- 配音凭证通过环境变量或宿主安全凭证能力读取，仅报告是否可用，不输出值。Keychain 为 macOS 可选适配，不是通用必需项。
- 不自动安装全部依赖；先列出当前阶段真正缺的项，按用户授权与环境规则处理。
- 未经验证的工具调用或缺失脚本不能写成已执行；遇到依赖问题先修复最小环节，避免切换整套生产路线。

## 宿主加载

技能包含 SKILL.md 和本目录参考文件。Codex 与 WorkBuddy 均能使用这种指令式结构，但安装入口、元数据和执行工具可能不同。读取相关参考文件时按 Skill 目录解析相对路径，不按项目根目录解析。

跨宿主验收至少包含：能找到技能并读到参考资料；能读取同一项目状态；不改原旁白生成代表分镜；在目标机的真实工具环境导出一段样片；通过内容、字幕和媒体检查。

首次配置见 install.md；默认动画与导出见 hyperframes.md。旧项目录制工具见 runtime.md。MiniMax 在线配音工具见 tts.md，凭证由使用者单独配置。不要把本机 macOS 的成功当作 Windows/Linux 已经过测试。
