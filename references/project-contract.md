# 项目与镜头记录

本文件规定最少需要记录的信息，不要求引入数据库或固定框架。已有项目尽量沿用原格式，只补确实缺少的记录。

## 项目简报与状态

建议在 production/project-state.md 记录：

- 课程名、受众、学习目标、目标时长和交付形式。
- 来源路径、权威旁白路径、来源冲突和未读材料。
- 选定的声音配置、输出规格、字幕类型（逐字或讲解摘要）。
- 样片路径、版本、确认范围和确认依据。
- 每章的配音/字幕/动画/检查/导出阶段、产物路径、有效输入版本、最后有效进度及实际执行的检查。若有子任务，记录文件所有者与交接结果。
- 当前障碍、NEED_CONFIRM 项及下一项具体动作。

文件路径相对项目根目录保存；运行时解析成绝对路径。状态必须有产物或用户确认作为依据，不能只依赖旧计划的勾选框。

## 镜头记录

| 字段 | 含义 |
| --- | --- |
| id / chapter | 镜头身份、教学章节；已有 ID 不随意重排 |
| sourceRef | 来源文件与可定位的位置 |
| title / narration | 标题、完整权威旁白 |
| input / action / output | 进入的材料、发生的操作、出现的结果 |
| humanCheckpoint | 业务中的人审点，或“不适用” |
| visualType / viewerText | 画面类型与明确允许显示的文案 |
| productionNote | 仅制作者可见的备注，禁止直接渲染 |
| audio | 路径、实测时长、文本/配置/文件指纹及内容核验状态 |
| captions | 文本、起止时间、与旁白对应关系 |
| render / checks | 当前视频路径、所用输入版本、实际检查结果 |

最初未配音时 audio 可留空并记录待生成；NEED_CONFIRM 表示未知，不能编造时长或声音 ID。初稿阶段不强制填全媒体字段，导出阶段再验证所需字段。

渲染时显式选用 viewerText 等允许展示字段，不把整个镜头对象转成文本。输入/动作/输出描述可能包含制作说明，必须经过观众文案整理后再上屏。

## 增量失效规则

旁白/声音配置变化 → 配音、字幕时间轴、对应视频需复核。

字幕文本布局/动画变化 → 对应视频需重做，配音可复用。

镜头顺序变化 → 批次/章节时间轴、合成清单需更新。

编码参数变化 → 优先利用仍可用的中间视频重新转码。

大文件不随 Skill 迁移。项目资料与媒体单独携带；技能只存方法，项目状态存进度。

## 一体版工具字段

配音和 HyperFrames 准备工具读取顶层 title/scenes。每镜头直接使用 audioPath（相对输入 JSON）；assets 是本地素材路径数组；captions 是相对本镜头音频的 {text,start,end} 数组。audio 对象可继续保留为审计记录。visualType/viewer 仅旧版 Canvas 工具必需，新画面不受三模板限制。prepare 输出的场景 start 为全局时间，captions 仍为镜头内相对时间。
